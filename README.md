# Mirror·镜 - 个人深度认知蒸馏系统

个人认知画像分析 Web 应用，基于 7 种题型测评系统，生成认知画像，识别思维弱点。

## 技术栈

- **框架**: React 19 + TypeScript
- **构建**: Vite 7
- **状态管理**: Zustand + localStorage
- **路由**: React Router v7
- **图表**: Recharts

## 功能

- ✅ 7种题型测评（价值判断力、逻辑严谨性、共情中立性、知识精确性、批判性思维、思维深度、融会贯通）
- ✅ 认知画像雷达图可视化
- ✅ 反直觉洞察生成
- ✅ 弱点识别与改进建议
- ✅ 重测对比功能
- ✅ 题库动态更新（联网）

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build
```

## 题库联网

应用支持联网获取最新题库，可在设置页配置题库 API 地址。
